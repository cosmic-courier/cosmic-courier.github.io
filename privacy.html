Privacy Policy

The Cosmic Courier publishing tool. Effective 18 November 2026.

Who uses the tool

The publishing tool is used only by the owner of The Cosmic Courier and El Correo Cósmico YouTube channels, to manage those channels. It is not offered to the public, and no other person's Google account is connected to it.

Google user data the tool accesses

When the owner signs in with Google, the tool requests access to the owner's YouTube channel in order to:

  • upload the channel's own videos as private drafts and add their caption files (scope youtube.upload);
  • post replies to comments on the channel's videos, only after the owner approves each reply (scope youtube.force-ssl);
  • confirm which channel is signed in (the channel's public handle).

Public comments on the channel's own videos are read through the YouTube Data API so that replies can be drafted for the owner's approval.

How the data is used and stored

  • Data is used only to provide these channel-management functions.
  • The sign-in token and channel data are stored only on the owner's own computer. They are not uploaded to any other server.
  • Google user data is not sold, not shared with third parties, not used for advertising, and not used to train AI models.
  • Public comment text may be processed by an AI assistant solely to sort comments and draft replies for the owner to review.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

Comments and drafted replies are kept for as long as they are useful for running the channel. Access can be revoked at any time at myaccount.google.com/permissions; the local token is then deleted.

Viewers

Watching the channel's videos does not involve this tool. YouTube's own privacy policy applies to viewers on YouTube.

Contact

Questions about this policy can be sent through the contact details on the channel's About page.
